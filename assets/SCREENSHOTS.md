# Assets Library artwork

Generated with npm run release:art to illustrate automatic generated asset discovery, using the compiled panel, controlled Orca bridge fixtures and original assets/samples vectors and Markdown. No live workspaces, transcripts, filesystem paths, credentials or external images are captured. The icon retains the product’s book glyph.

- icon.png: 512 × 512 original book mark with an orange gradient and purple glyph.
- cover.png: 1600 × 1000 current compiled Library panel, an orange/purple frame, a brighter backdrop and bold product title.
- screenshot-dark.png and screenshot-light.png: actual compiled card galleries within listing compositions.
- screenshot-list.png: actual compiled List view.
- screenshot-markdown.png: actual compact rendered Markdown inspector.
- social.png: 1280 × 640 GitHub social preview featuring the current compiled panel in the same orange/purple frame as the cover.

Artwork uses deterministic SVG compositions rendered by Chromium and Sharp, following the sibling plugins’ screenshot-based release-art approach. Bright orange/purple frames, a brighter plum backdrop and bold product names follow the sibling Sidequest cover’s strong visual direction; panel captures keep their native appearance. No generative image API, proprietary fonts, borrowed brand logos or resource downloads are used. System/browser fonts are rasterized; none are distributed. Raw fixture captures remain in ignored development storage.
