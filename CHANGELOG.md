# Changelog

## 1.0.0

- Automatically discover agent-generated images, SVGs, videos, Markdown and HTML inside the current worktree, with live updates as files change.
- Recover generated worktree assets from recorded chat file changes when a worktree opens.
- Browse generated assets in Orca’s right sidebar with persistent Cards and List views, the active worktree name, and supported project icons and colors.
- Find assets with filename and path search, file-type filters and sorting.
- Inspect images with fit, zoom and pan controls; play supported videos and read compact rendered Markdown or HTML source previews.
- Open assets in Orca’s editor, open HTML in Orca’s browser, and copy paths or asset references.
- Refresh generated-asset discovery on demand and optionally include unavailable files through discovery settings.
- Preserve assets and their changes across restarts and worktree switches, with duplicate files shown once.
- Use responsive light and dark layouts, keyboard navigation, reduced-motion support, and subtle asset entrance animations.
- Keep previews and galleries scrollable with fading bottom edges and scrollbars shown on hover or focus.
